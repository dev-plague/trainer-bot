## Qué se ve

- El RIR aparece en lenguaje llano y la base del día se muestra una sola vez; la ayuda del
  concepto está en el ícono `?`.
- La tarjeta destacada muestra la próxima sesión pendiente, las pestañas marcan los días
  completados y existe un estado de semana cumplida.
- Cambiar ejercicio es solo un drawer sobre el plan, con equipo, nivel, badge «Por tiempo»,
  una única X y aviso de confirmación.
- La sesión muestra «Serie 1 de 2», el descanso con marca de tiempo y la cuenta regresiva del
  isométrico; la barra de progreso refleja el avance real.
